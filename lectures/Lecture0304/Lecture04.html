Matrices in R

Overview

  • Braun and Murdoch give a section in Chapter 2 and Book of R gives a whole Chapter 3
  • And you can read entire books on matrix algebra (lower division) then linear algebra (upper division)
  • The emphasis you wish to give will depend heavily on your career trajectory
  • A matrix could be thought of as a vector with row and column dimensions imposed on it
  • Matrices then are rectangular
  • Matrices, like vectors, must be a single data type (will coerce data if not)
  • The matrix() function needs a vector and at least one dimension to construct a matrix.
  • An array is just a multidimensional matrix in R

operations on vectors and matrices

The Data Frame

Data Frames

  • The Matrix and working with it leads us into the Data Frame
  • Most real data in R are stored as data frames, they are like spreadsheets
  • We saw the built-in iris. Iris is rectangular like a matrix.
  • But Iris has mixed numeric and non-numeric information. Matrices are only one data type either via construction or coercion.

Extract Using Names

What is a low level language? Assembly v R

.model small
.stack 100h

.data
a dw 2
b dw 5

.code
main proc
    mov ax, @data
    mov ds, ax

    mov ax, a
    mov bx, b
    add ax, bx

    add al, 30h
    mov dl, al
    mov ah, 02h
    int 21h

    mov ah, 4Ch
    int 21h
main endp
end main
a <- 2
b <- 5

a + b

For your consideration

  • In assembly, we must tell the computer every tiny step. Assembly required humans to think/communicate like machines.
  • In R, Python, and other modern languages, we write what we want in a compact and more natural form
  • Programming languages evolved to let humans think less about machine details and more about ideas, data, and problems.
  • LLMs are part of the same long arc of evolution. They allow us to express intent in ordinary language. So “please add 2 and 5” as in the previous slide.

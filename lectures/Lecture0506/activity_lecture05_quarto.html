Something tabled

Some data is better tabled, this is a little trick that will make nice tables. Workflow:

  • first we table a non-numeric variable
  • then convert the table to named data frame
  • use the colnames() function and overwrite the names with new names
  • then use the kable() function to generate a nice table
  • extras - the kableExtra library has styling options for output
  • the |> is called a pipe and passes repetitive information through the code block
  • You don’t need this for a basic report, I’m demonstrating what is possible
Code
my_result <- table(penguins$species) |> as.data.frame.table()
colnames(my_result) <- c("Species", "Count")
kable(my_result) |> kable_styling() |>
  row_spec(seq(1, nrow(my_result), by = 2), background = "cyan") |>  
  # Color for odd rows
  row_spec(seq(2, nrow(my_result), by = 2), background = "yellow")

A Visualization generated by R

Typically, R uses a formula representation for table specification. In my example body_mass ~ species or body mass as a function of species.

Code
boxplot(body_mass ~ species, data = penguins, 
        col = c("red", "yellow", "green"),
        main = "Penguin Body Mass by Species",
        xlab = "Species",
        ylab = "Body Mass"
)

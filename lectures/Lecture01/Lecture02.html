Activity #5

  • (We probably don’t have the time but) I’d like us to examine an R script (.R), an R Markdown document (.rmd), and a Quarto document (.qmd).

They do the same things generally but as a rule:

  • Use documents/notebooks (.rmd/.qmd) when exploring, explaining, and communicating
  • Use .R scripts when in production mode and scaling matters (execution and reuse)
  • You can easily convert .rmd/.qmd to .R and reverse

What is (R)Markdown?

  • Markdown is a markup language (a language for presenting information, not for analysis) for writing formatted text using plain text symbols.
  • You write something that easy to read, and software converts it into nicely formatted output like HTML, PDF, or slides.
  • The variant used by RStudio and Positron is “Pandoc Markdown” which has executable code chunks (R, but Python also) VS code uses “Common Mark” so a lot of the power of Pandoc is not default but can be added via extensions.
  • This slide presentation was written in Markdown using Quarto in Positron
  • Many of your upper division stats courses will use RMarkdown in RStudio

Communication (RMarkdown/Quarto)

  • For a data engineer, the “code” or “script” is the product.
  • For a working statistician, the deliverable is the product.
  • An IDE such as RStudio running R with RMarkdown/Quarto (.rmd/.qmd) is designed to produce the deliverable
  • An IDE such as RStudio can also produce scripts (.R) which are “code”
